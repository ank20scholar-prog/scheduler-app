# Scheduler

A personal class-schedule and task tracker, built as a Progressive Web App.

Plain HTML, CSS and JavaScript — no framework, no build step, no dependencies,
no backend. All data stays in the browser's local storage on your own device;
nothing is uploaded anywhere.

## Install it

Open the site on your phone, then **Share → Add to Home Screen**. It launches
full screen with its own icon and works offline.

## Use it

- **Schedule** — add your weekly classes, colour-coded, with rooms and times
- **Today** — a live timeline with a line that tracks the current time; tap an
  empty gap to fill it
- **Tasks** — set a priority and a deadline; the list ranks itself by urgency

Starts empty. Add your own classes, or import a backup from the Schedule tab.
